# MiniMarket Odoo

Solución de gestión para pequeños comercios tipo minimarket, desarrollada sobre Odoo 18.

## Descripción

Este proyecto tiene como objetivo desarrollar una solución vertical para la gestión de un minimarket, aprovechando la funcionalidad estándar proporcionada por Odoo y extendiéndola cuando sea necesario.

La aplicación busca proporcionar una base sencilla, mantenible y escalable para gestionar las operaciones habituales de un pequeño comercio.

## Objetivos

- Analizar las funcionalidades estándar disponibles en Odoo.
- Identificar funcionalidades complementarias disponibles en OCA.
- Reutilizar y extender la funcionalidad existente antes de desarrollar soluciones propias.
- Diseñar una arquitectura modular y mantenible.
- Aplicar buenas prácticas de desarrollo de Odoo.
- Incorporar seguridad, lógica de negocio, automatizaciones, informes, integración externa y pruebas.

## Tecnologías

- Odoo 18
- Python
- PostgreSQL
- XML
- Git / GitHub

## Estado del proyecto

🚧 En desarrollo.

La arquitectura funcional y los componentes definitivos se determinarán después del análisis de Odoo estándar y de los módulos OCA compatibles con Odoo 18.
